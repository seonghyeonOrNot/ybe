# Component Patterns — y-BE Admin

## Button (.btn 베이스 + 색상 클래스로 분기)

| Variant | 클래스(추정) | 채움색 | 용도 |
|---|---|---|---|
| Primary | .btn.point | #312E98 | 검색, 저장 등 핵심 액션 |
| Secondary | .btn.positive / point2 | #3371FF | 수정, 상세, 보기 |
| Dark | point3 | #12114E | 사진 변경 등 더 강한 강조가 필요한 보조 액션 |
| Outline (각 variant별) | 동일 색 테두리 + 흰 배경 | — | 취소, 삭제, 이력조회 |

**크기**: 13px(테이블 내 소형), 15~16px(일반)
**세그먼트 토글**: 두 버튼이 붙어서 바깥쪽 모서리만 radius 처리되는 패턴 (예: 일간/기간 전환)

## Tab — 3 variants (통합하지 말고 유지)

| Variant | 사용처 | 활성 스타일 | 비활성 스타일 |
|---|---|---|---|
| Rounded | 상단 콘텐츠 탭 (전체현황, 구성원 수정 등) | #2285F1 채움 + 상단만 16px 라운드 | 텍스트만 #808CAF |
| Toggle | 게시판 관리 (공지사항/자유게시판) | #312E98 채움, radius 10px (사각 pill) | — |
| Stepped | 연차 설정 "공통" 등 | 세로형, Stepped Shadow 적용 | — |

## Form Elements

- **Input**: pill radius 126px, 테두리 #CCC
- **Radio/Checkbox**: 원형 커스텀 아이콘, 선택 시 네이비 dot
- **날짜 필드**: 캘린더 아이콘 내장
- **숫자 입력**: 단위 텍스트 붙임형 (예: "8 시간")
- **필터 라벨-필드 결합형**: 비대칭 radius로 한 몸처럼 연결. 활성 필터 = 네이비(#312E98), 잠금/비활성 = 그레이(#9EADCC) — 색만 바뀌는 단일 컴포넌트의 variant로 취급

## Data Display

- **테이블**: 다크 네이비 헤더(#2A2873) + 흰 텍스트, 바디는 흰 배경 + 라인 구분자(줄무늬 없음). 5개 이상 페이지에서 동일 재사용.
- **통계 카드**: 라이트 인디고(#F1F4FF) 배경, 숫자 29.6px/weight 700
- **조직도**: jsTree 기반 트리 컴포넌트
- **게시판 고정글**: 연한 블루 배경 + 압핀 아이콘으로 하이라이트
- **페이지네이션**: 지름 32px 원형 버튼, 현재 페이지만 #8D9DC4 채움, 나머지는 텍스트만

## Composite Components

- **프로필 사진 편집 UI**: 이미지 업로드 + 상태 뱃지(pill, #D9F2FC 배경, 예: "7년 2일 재직 중") + 핑크 헬퍼 텍스트 조합
- **Notice Banner**: 체크 아이콘 불릿 리스트, 페이지 상단. 전체현황/구성원 관리/연차 설정/게시판 관리 등 4개 이상 페이지에서 반복 — 공통 컴포넌트로 확정
- **등록 드롭다운**: "구성원 등록" 등 버튼 클릭 시 나오는 카드형 드롭다운, radius 10px + Floating shadow

## Modal

- **modal.mid**: 1200px 폭, 배경 #FEFEFE, radius 26px
- 휴가 대상자 등록/수정, 변경이력 조회, 사용이력 조회 등 **관리자 화면의 모든 모달이 이 구조를 재사용**
- 사용자 화면의 "휴가 선택" 모달은 이 구조를 따르는지 미검증 (별도 확인 필요)

## 기존 클래스 네이밍 참고 (역설계 확인분)

.btn.point, .btn.positive, badge1-1, .txt-notice.info, .txt-inform, modal.mid

이 이름들은 실제 코드베이스에서 발견된 것이므로, Claude Design/Code로 새 화면을 만들 때 새 이름을 짓지 말고 이 네이밍을 우선 확인하고 재사용할 것.
