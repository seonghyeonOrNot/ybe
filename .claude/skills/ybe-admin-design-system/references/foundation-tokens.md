## Typography

폰트: **Montserrat + Gmarket Sans** 조합

| 스케일명 | Size | Weight | 용도 |
|---|---|---|---|
| Display | 30px | 800 | 페이지 타이틀 (예: "전체 현황") |
| Section Title | 20px | 800 | 설정 페이지 섹션 헤더 |
| Title | 19px | 700 | 활성 탭 텍스트 |
| Title-inactive | 18px | 600 | 비활성 탭 텍스트 |
| Sidebar | 17px | 600~800 | 사이드바 메뉴 (활성시 800) |
| Body-lg | 16px | 600 | 버튼, 셀렉트 등 기본 UI |
| Body | 14px | 600 | 테이블 셀 |
| Caption | 13px | 600 | 소형 버튼 |

**주의**: weight가 400~500이 아니라 600~800에 몰려 있음. 기본 폰트 굵기를 쓰면 톤이 실제 화면보다 얇아 보임.

## Radius

| 패턴 | 값 | 적용 대상 |
|---|---|---|
| Pill | 100px 이상 (117~144px, 인풋 126px) | 버튼, 셀렉트, 인풋 |
| Sharp | 0 | 테이블, 탭 콘텐츠 영역 |
| 비대칭(라벨-필드 결합형) | 30px 10px 33px 30px | 필터 라벨이 셀렉트/인풋과 한 몸처럼 이어질 때 |
| 탭 활성 상단 | 16px (상단 모서리만) | Rounded 탭 활성 상태 |
| 카드/배너 | 10~20px | 일반 카드, 알림 배너 |
| 통계 카드 | 16px | Stat card |
| 드롭다운 메뉴 | 10px | 플로팅 메뉴 |
| 모달(modal.mid) | 26px | 등록/수정/이력조회 모달 |

## Shadow

| 이름 | 값 | 용도 |
|---|---|---|
| Floating | 7px 6px 15px -3px rgba(0,0,0,0.4) | 드롭다운 메뉴 등 일반 플로팅 UI |
| **Stepped Shadow Header** (y-BE 고유 시그니처) | #8FBFF9 계열로 1px~7px씩 점점 커지는 7단 계단식 box-shadow | 연차 설정 / 컬러테마 설정 페이지의 섹션 헤더(H3). 카드가 쌓인 듯한 독특한 룩 — 다른 서비스에 없는 디테일이므로 재현 시 유의 |

## Layout

- 상단 GNB: 로고 + 회사명 + 로그아웃
- 좌측 LNB: 1depth 다크네이비 배경, 2depth는 hover/active 시 서브메뉴 노출
- 우측 콘텐츠: 타이틀 + 탭 + (좌측 트리/검색 필터 카드 + 우측 리스트/테이블 카드)의 2단 카드 구성
