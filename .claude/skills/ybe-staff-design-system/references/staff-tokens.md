# Foundation Tokens — y-BE Staff (사용자 화면)

Shape/spacing/타이포 스케일은 ybe-admin-design-system의 foundation-tokens.md와 동일합니다. 여기서는 **사용자 화면에서 다르게 확인된 값만** 정리합니다.

## Color — Admin ↔ Staff 테마 매핑

| Semantic 역할 | Admin 값 | Staff 값 | 비고 |
|---|---|---|---|
| Primary / 주요 액션 | #312E98 (네이비) | #00B4B8 (틸/민트) | 앱별 테마 토큰만 교체되는 구조 확인됨 |
| 활성 탭 강조 | #2285F1 | #00B4B8 | 동일 패턴, 색만 교체 |
| 사이드바 배경 | #1B164D (다크 네이비) | #00B4B8 (틸) | 레이아웃 형태 자체가 다름 (아래 참고) |
| **토글 스위치 on** | 해당 없음(admin에 토글 컴포넌트 미확인) | #3371FF (블루) | **예외 — 틸이 아님.** admin의 액션 블루(#3371FF)와 동일한 값 |

> 이 서비스는 컬러테마 설정 페이지의 "5종 브랜드 컬러 선택" 기능과 동일한 방식으로, Admin/Staff 두 앱에 서로 다른 accent color가 매핑되어 있는 것으로 확인됨. 새로운 색을 하드코딩하지 말고 이 매핑 관계를 기준으로 삼을 것.

## Layout — Sidebar 차이

| 항목 | Admin | Staff |
|---|---|---|
| 형태 | 텍스트 기반 풀 네비게이션 | 아이콘 전용 |
| 폭 | (풀사이즈) | 87px |
| 배경 | 다크 네이비 #1B164D | 틸 #00B4B8 |
| 활성 표시 | 서브메뉴 노출(hover/active) | rgba(0,0,0,0.15) 반투명 오버레이 + radius 10px |

## Header 차이

Staff 화면 상단에는 Admin에 없는 요소가 추가됨:

- 관리자 페이지 전환 버튼 (역할 전환 가능한 하이브리드 헤더)
- 알림 벨 아이콘
- 프로필 아바타

## Typography

Admin과 동일한 6단 스케일 재사용 확인됨 (탭 19px/700 vs 18px/600 등 그대로). 별도 스케일 추가 없음.

## Modal Size Variants (전체 서비스 공통 규칙 갱신)

| 클래스 | 폭 | 사용처 |
|---|---|---|
| modal.mid | 1200px | Admin — 휴가 대상자 등록/수정 등 |
| modal.wide | 1000px | Staff — 휴가 선택 등 |

두 클래스 모두 배경 #FEFEFE, radius 26px은 동일. **폭만 컨텍스트에 따라 분기.** 새 모달 필요시 이 표에 없는 사이즈를 임의로 만들지 말고, 둘 중 가까운 쪽을 쓰거나 실측을 요청할 것.
