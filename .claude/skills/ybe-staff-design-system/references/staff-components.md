# Component Patterns — y-BE Staff (사용자 화면 전용)

Admin과 공유하는 버튼/탭/테이블 기본 규칙은 ybe-admin-design-system의 component-patterns.md 참고. 여기서는 **사용자 화면에서만 확인된 컴포넌트**를 다룹니다.

## 아이콘 사이드바

- 폭 87px, 배경 #00B4B8(틸)
- 활성 메뉴: rgba(0,0,0,0.15) 반투명 검정 오버레이 + radius 10px
- Admin의 텍스트 기반 풀 네비게이션과 완전히 다른 레이아웃 — 컴포넌트 이식 시 재사용 불가, 별도 구현 필요

## 캡슐형 탭 (Capsule Tab) — 2 Variant

Admin의 Rounded/Toggle/Stepped 탭과 별개로, 사용자 화면에만 존재하는 새 패턴. 이름은 같지만 배경 처리가 다른 **두 개의 서브 variant**로 구분할 것:

| Variant | 사용처 | 컨테이너 배경 | 활성 항목 스타일 |
|---|---|---|---|
| Capsule-MyPage | 마이페이지 | 연한 그레이 pill | 틸색 pill이 활성 탭 위에 얹힘 |
| Capsule-Modal | 휴가 선택 모달 (연차/대상/비대상 구분) | rgba(0,180,184,0.12) (브랜드컬러 12% 투명도) | 흰색 pill |

세그먼트 컨트롤에 가까운 형태 — 새로 만들 때 어느 컨텍스트인지에 따라 컨테이너 배경을 다르게 적용할 것.

## 토글 스위치 (Toggle Switch)

- On 상태 배경: #3371FF (블루 — **틸이 아닌 유일한 예외**)
- Radius: 30px (pill)
- Off 상태 스타일은 미확인 — 실측 필요

## 버튼 — 초소형 사이즈 + Disabled 상태

기존 Admin 스킬에 있는 13px/15~16px 사이즈에 추가되는 새 사이즈:

| 항목 | 값 |
|---|---|
| 크기 | 90×24px |
| 폰트 | 12px |
| 사용처 | 업무관리 출근/퇴근 버튼 등 |

**Disabled 상태** (전체 서비스에서 최초로 확인된 비활성 버튼 규칙):

| 속성 | 값 |
|---|---|
| 배경 | #F4F4F4 |
| 텍스트 | #BBBBBB |
| 테두리 | #E8E8E8 |

색을 진하게/연하게 빼는 방식이 아니라 완전히 무채색 톤으로 처리하는 방식. Admin 화면의 Disabled 버튼이 동일한 규칙을 쓰는지는 미검증.

## Modal — 휴가 선택 (전자결재 > 휴가 신청서 작성)

**클래스**: modal.wide (1000px, 배경 #FEFEFE, radius 26px, padding 30px 30px 20px)

구조 (위→아래):

1. 상단 안내 배너 — 연한 블루 배경 + 체크 아이콘 (Admin의 Notice Banner와 동일 패턴)
2. 캡슐형 세그먼트 탭 — 연차 / 대상 / 비대상 (Capsule-Modal variant 적용)
3. "소멸 임박건만 보기" 체크 필터
4. 검색 인풋 + 원형 검색 버튼 (40×40px)
5. 리스트 영역 — 빈 상태는 Admin과 동일한 문서 아이콘 + 안내 문구
6. 우측 하단 "확인" 버튼 (틸색 채움)

**닫기**: 별도 취소 버튼 없이 X 아이콘 하나로만 닫음 (Admin 모달과 다른 점 — Admin은 취소/저장 버튼 조합이 일반적).
