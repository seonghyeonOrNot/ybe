# y-BE 사용자(직원) 디자인 시스템

y-BE 사용자 화면 4개 영역(업무관리, 마이페이지, 일정, 전자결재)을 실제로 열어 computed style을 뽑아 역설계한 디자인 시스템입니다.

## 관리자(Admin) 스킬과의 관계 — 반드시 먼저 읽을 것

이 서비스는 **관리자용/사용자용이 완전히 다른 두 시스템이 아니라, 하나의 컴포넌트 엔진에 앱별 컬러 테마만 다르게 주입하는 구조**입니다. 실제로 버튼·탭·모달의 클래스명, radius, padding, spacing 규칙은 ybe-admin-design-system 스킬과 100% 동일하고, **바뀌는 건 브랜드 강조색(accent color)뿐**입니다.

- **Shape/Spacing 규칙**(radius, padding, 폰트 사이즈/weight 스케일, 그림자 종류 등)은 ybe-admin-design-system의 Foundation을 그대로 따릅니다. 이 스킬에서 별도로 반복 기술하지 않은 값은 admin 스킬 값을 그대로 적용하세요.
- **다른 건 색상 토큰과, 이 문서에 명시된 사용자 화면 전용 컴포넌트(아이콘 사이드바, 캡슐형 탭, 세그먼트 컨트롤, 토글, 초소형 버튼)뿐입니다.**
- 두 스킬 중 하나에서 shape/spacing 규칙이 바뀌면(예: radius 값 변경), **반드시 다른 쪽 스킬도 같이 업데이트할 것.** 공유 규칙이 한쪽만 갱신되면 두 화면이 조용히 어긋나게 됩니다.

## 사용 원칙

1. **색상만 다르다고 가정하지 말고 예외를 확인할 것.** 대부분의 컴포넌트는 admin의 네이비/블루 대신 틸(#00B4B8) 하나로 통일되지만, **토글 스위치는 예외적으로 틸이 아니라 블루(#3371FF)를 씁니다.** 이 예외를 "실수"로 보고 임의로 틸로 바꾸지 마세요.
2. **모달 사이즈는 컨텍스트에 따라 분기됩니다.** admin의 modal.mid(1200px)와 별개로, 사용자 화면에는 modal.wide(1000px)가 있습니다. 새 모달을 만들 때 어느 사이즈에 해당하는지 먼저 확인하세요.
3. **미검증 항목은 단정하지 말 것.** Disabled 버튼 스타일은 사용자 화면(출퇴근 버튼)에서만 확인됐고, 관리자 화면도 같은 규칙을 쓰는지는 검증되지 않았습니다.

## Foundation 차이점

상세 표는 references/staff-tokens.md 참고. 핵심 요약:

- **Primary 브랜드 컬러**: 틸/민트 #00B4B8 단일 색 (admin은 네이비 3단 + 블루 2단)
- **예외**: 토글 스위치 on 상태만 블루 #3371FF (admin의 액션 블루와 동일)
- **레이아웃**: 사이드바가 admin(풀 네비게이션, 다크 네이비)과 다르게 폭 87px 아이콘 전용(배경 #00B4B8), 활성 메뉴는 rgba(0,0,0,0.15) 오버레이 + radius 10px
- **헤더**: "관리자 페이지 전환 버튼", 알림 벨, 프로필 아바타 추가 (역할 전환 가능한 하이브리드 헤더)

## Components (사용자 화면 전용)

상세 스펙은 references/staff-components.md 참고. 핵심 요약:

- **아이콘 사이드바**: 폭 87px, 배경 틸, 활성 메뉴 반투명 오버레이
- **캡슐형 탭 — 2 variant**: (a) 마이페이지형 — 연한 그레이 pill 컨테이너 안에 활성 탭만 틸 pill, (b) 휴가 선택 모달형 — 컨테이너 배경 rgba(0,180,184,0.12), 활성 항목은 흰색 pill. 이름이 같아도 배경 처리가 다른 별개 variant로 취급할 것.
- **토글 스위치**: on 배경 #3371FF, radius 30px pill (색상 예외 케이스)
- **버튼 — 초소형(btn small)**: 90×24px, 폰트 12px. **Disabled 상태**: 배경 #F4F4F4, 텍스트 #BBBBBB, 테두리 #E8E8E8 (무채색 처리)
- **modal wide**: 1000px 폭, 배경 #FEFEFE, radius 26px, padding 30px 30px 20px (radius/배경은 admin의 modal.mid와 동일 — 폭만 다름)
- **휴가 선택 모달** (전자결재 > 휴가 신청서 작성): 상단 안내 배너(연한 블루+체크아이콘) → 캡슐형 세그먼트 탭(연차/대상/비대상) → "소멸 임박건만 보기" 체크필터 → 검색 인풋+원형 검색버튼(40×40px) → 리스트(빈 상태는 admin과 동일한 문서아이콘+안내문구) → 우측 하단 틸색 "확인" 버튼. 취소 버튼 없이 X 아이콘으로만 닫음.

## 알려진 리스크 / 미검증 항목

- Disabled 버튼 스타일이 관리자 화면에서도 동일하게 적용되는지 미확인 — 확인 전까지는 "사용자 화면에서 검증된 규칙"으로만 취급할 것.
- 사용자 화면의 다른 페이지(업무관리 외 상세 화면들)는 아직 전수 조사되지 않았을 수 있음 — 새 화면 작업 시 여기 없는 컴포넌트가 나오면 추측하지 말고 실측을 요청할 것.
